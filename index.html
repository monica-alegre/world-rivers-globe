About this Project

Interactive 3D globe of the world's major rivers with Wikipedia-linked information in popups.

Data Sources

Natural Earth

10m Rivers + Lake Centerlines

Wikipedia / Wikidata

River information in popups is retrieved from Wikipedia and Wikidata.

NASA Visible Earth

Bathymetry basemap (edited version used).

Technologies

Built with globe.gl (Three.js-based WebGL globe visualization), integrated with Wikidata API for river information and Wikipedia REST API for summaries and images. Data processing with GeoJSON and interactive filtering.
